{"status":"ok","service":"catalog-service"}
{"status":"ok","service":"order-service"}
{"status":"ok","service":"payment-service"}

=== 2. Каталог товаров (catalog-service)
$ curl -s http://localhost:5001/api/products
[{"id":1,"name":"Ноутбук Aero 14","price":89990.00,"stock":5},{"id":2,"name":"Смартфон Nova X","price":39990.00,"stock":10},{"id":3,"name":"Наушники Pulse","price":7490.00,"stock":25},{"id":4,"name":"Монитор View 27","price":24990.00,"stock":7}]

=== 3. Добавить новый товар
$ curl -s -X POST http://localhost:5001/api/products -H 'Content-Type: application/json' -d '{"name":"Клавиатура Type One","price":4990,"stock":15}'
{"id":5,"name":"Клавиатура Type One","price":4990,"stock":15}

=== 4. Оформить заказ: order-service -> catalog-service (резерв) -> payment-service (оплата)
$ curl -s -X POST http://localhost:5002/api/orders -H 'Content-Type: application/json' -d '{"customerName":"Иван Петров","items":[{"productId":2,"quantity":1},{"productId":3,"quantity":2}]}'
{"id":1,"customerName":"Иван Петров","status":"Paid","total":54970.00,"paymentId":1,"comment":null,"createdAt":"2026-11-10T13:09:18.7856831Z","items":[{"id":1,"orderId":1,"productId":2,"productName":"Смартфон Nova X","unitPrice":39990.00,"quantity":1},{"id":2,"orderId":1,"productId":3,"productName":"Наушники Pulse","unitPrice":7490.00,"quantity":2}]}

=== 5. Остатки уменьшились (товар зарезервирован)

{"id":3,"name":"Наушники Pulse","price":7490.00,"stock":23}
